# Browser prototype milestones

## 1. Printable seam templates — implemented

Draw and delete seams; undo/redo; trace images; import/export projects; download mirrored Letter/A4 PDFs with physical dimensions, outer allowance, overlap guides, and a calibration square. PDF/core checks and browser interaction tests cover this workflow.

**Next acceptance step:** print the sample on paper, measure its calibration square and assembled outline, and record the printer, PDF reader, settings, and measurements. This physical check remains pending.

## 2. A useful FPP foundation

Detect closed regions, assign piece labels, define separate sections, and let the designer choose sewing order. Add representative sewable and unsewable examples before claiming automatic FPP validation.

## 3. Faster design iteration

Move vertices, zoom/pan, color pieces, and improve tracing. Keep physical PDF dimensions covered by regression tests.

## 4. Quilt planning and fabric

Port the desktop quilt composer and color matching. Keep manufacturer display colors identified as approximations.

Choose one small feature at a time, validate it in the browser, and retain the calibration examples as the PDF engine evolves.
